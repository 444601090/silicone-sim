# dsh-body · 机体

> 三插件闭环里的「机体」层。总协议见 `../THREE-PLUGINS.md`。

## 它做什么

每 60 秒一拍，纯本地计算（天气除外），不烧模型：

1. 读 `body/state.json`，按距上次更新的分钟数推进生物钟
2. 维护「醒 / 睡」状态（能自己睡、自己醒）
3. 刷新感受：时间（小时）+ 天气（Open-Meteo 免 key，自动定位 ip-api）
4. 写回 `body/state.json`，供思维和行为插件读

## 生物钟参数（v1）

| 项 | 值 |
| --- | --- |
| 醒着耗精力 | 白天 4.2%/小时，夜里 5.4%/小时 |
| 睡着回精力 | 12%/小时 |
| 醒着耗体力 | 1.5%/小时；发呆（思维 idle > 0.6）时改成 +2%/小时 |
| 睡着回体力 | 18%/小时 |
| 自动睡 | 精力 < 0.15，或夜间（22~6 点）精力 < 0.35 |
| 自动醒 | 精力 ≥ 0.9，或白天 7 点后精力 > 0.6 |
| 单次最长推进 | 180 分钟（关机一天不会一夜清零） |

## 感受

- 时间：当前小时
- 天气：温度 / 湿度 / 天气文字（WMO 码转中文），每 30 分钟刷新
- 配置 `body/config.json`：`{ "天气开关": true, "自动定位": true, "纬度": 39.9, "经度": 116.4, "天气刷新分钟": 30 }`
